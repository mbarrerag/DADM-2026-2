# Reto 8: Directorio con SQLite

Aplicacion Android para registrar empresas de desarrollo de software usando SQLite local.

Incluye:

- Crear, editar y eliminar empresas.
- Nombre, sitio web, telefono, correo, productos y servicios.
- Clasificacion por tipo de empresa.
- Filtro por nombre y clasificacion.
- Confirmacion antes de eliminar.

Este reto no requiere Firebase: los datos se almacenan localmente en SQLite dentro del dispositivo.
