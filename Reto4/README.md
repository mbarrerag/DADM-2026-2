# Reto 4

Aplicacion Android Tic-Tac-Toe extendida con menus y dialogos.

## Incluye

- Menu XML con New Game, Difficulty, About y Quit.
- Dialogo para seleccionar dificultad Easy, Harder o Expert.
- Dialogo de confirmacion para salir.
- Dialogo About con icono personalizado.
- Logica de juego separada en `TicTacToeGame.java`.

## Ejecutar

Abre esta carpeta en Android Studio:

```text
C:\Users\Stepe\Documents\DADM-2026-2\Reto4
```

O compila desde PowerShell:

```powershell
.\gradlew.bat assembleDebug
```
