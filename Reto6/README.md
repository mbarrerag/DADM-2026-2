# Reto 6

Aplicacion Android Tic-Tac-Toe extendida con cambio de orientacion y estado persistente.

## Incluye

- `BoardView` custom para dibujar la grilla y las fichas X/O.
- Entrada tactil sobre el tablero dibujado.
- Efectos de sonido para jugador y Android.
- Delay de un segundo antes de la jugada de Android.
- Layout portrait y layout landscape.
- Conserva tablero, mensaje, turno y siguiente jugador al rotar.
- Guarda puntajes y dificultad con SharedPreferences.
- Menu XML con New Game, Difficulty, About y Reset Scores.
- Dialogo para seleccionar dificultad Easy, Harder o Expert.
- Dialogo About con icono personalizado.
- Logica de juego separada en `TicTacToeGame.java`.
